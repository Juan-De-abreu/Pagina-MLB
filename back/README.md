# ⚾ MLB Stats Web App backend

Bienvenido al repositorio del proyecto **MLB Stats Web App backend**. Aquí encontrarás una aplicación web interactiva para consultar estadísticas de la Major League Baseball (MLB).

## 🚀 Características

- Consulta de estadísticas de jugadores.
- Interfaz intuitiva y atractiva para ver el acceso al api.
- Filtros avanzados para personalizar la búsqueda.

## 🛠️ Tecnologías utilizadas

- **Backend:** php
- **Frontend:** React, boostrap CSS
- **Base de datos:**  phpmyadmin, mysql


## 📦 Instalación

```bash
git clone https://github.com/juan-de-abreu/Pagina-MLB.git
cd Pagina-MLB/back
# Configura tu servidor web (Apache/Nginx) para servir los archivos PHP
# Asegúrate de tener PHP y MySQL configurados
# Importa la base de datos desde phpMyAdmin o usando el archivo
```
